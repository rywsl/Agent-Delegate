本地 agent 能做什么

  • delegate_task：提交一个完整、自洽的任务并等待结果（云端 agent 自主执行，不能被逐步操控）。
  • create_upload：获取一次性上传地址，用 curl 上传项目目录 / 大文件，避免把文件内容塞进工具参数。
  • wait_task / cancel_task / list_tasks：等待、取消、列出任务。
  • 返回内容仅包含：结果报告、工作区 patch、/outputs 下的输出文件（均为限时下载链接）和费用。执行过程细节只在本站展示。
